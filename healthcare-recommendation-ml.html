System Architecture

Six Integrated AI/ML Layers

Working together to personalise every patient's care journey

📊
Pima Diabetes Dataset Backend
768 real patient records (Pima Indians) embedded and processed in-browser. Features include glucose, BP, BMI, age, insulin, and diabetes pedigree function.
🌲
Random Forest Classifier
100 bootstrap-aggregated decision trees trained in-browser with feature importance scores. Gini impurity splitting with max_depth constraints for generalization.
📈
Logistic Regression (SGD)
Gradient descent with sigmoid activation trained over 500 epochs. Feature normalization via StandardScaler equivalent for stable convergence.
🔵
KNN Classifier
k=5 nearest neighbours using Euclidean distance. Training is pure memorization; prediction uses majority vote from 5 closest training samples.
🧮
Naïve Bayes (Gaussian)
Estimates Gaussian distributions per feature per class. Uses Bayes' theorem with independence assumption for fast probabilistic classification.
🔬
Decision Tree (CART)
Recursive binary splitting using Gini impurity. Builds interpretable tree structure with max_depth=8 to balance accuracy and overfitting.
